Joy Go Platform V1.0 Beta 1.8.2
忘記密碼功能更新包

上傳方式：
1. 解壓縮本 ZIP。
2. 將解壓縮後的所有檔案，上傳至 GitHub 專案最外層。
3. 遇到同名檔案時選擇覆蓋。
4. 等候 GitHub Pages 約 1 至 3 分鐘完成更新。
5. Safari 若仍顯示舊版，請重新整理頁面一次。

測試方式：
1. 請先使用另一個測試帳號，或確認目前登入裝置保持登入。
2. 開啟會員中心，選擇「忘記密碼」。
3. 輸入註冊 Email，按「寄送重設密碼信」。
4. 到信箱點開連結；若沒看到，請檢查垃圾郵件。
5. 輸入兩次新密碼（至少 8 個字元），按「儲存新密碼」。

本次修改：
- 棋盤內會員中心：完整中文重設密碼畫面。
- 獨立會員頁：新增「忘記密碼」與新密碼設定頁。
- 兩次密碼一致性檢查。
- 更新快取版本，降低 Safari 顯示舊頁面的機會。

注意：
- 不會刪除會員、棋譜或管理員權限。
- Supabase 原密碼無法查看，只能重設。
- 若重設信連結被 Supabase 阻擋，請在 Supabase Authentication 的 URL Configuration
  加入：https://jugopower.github.io/-AlphaTraderAI-Pro-V5/
