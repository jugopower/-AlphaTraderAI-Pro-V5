# AlphaTrader AI Pro V5 — Build022.4.5

## 修正內容

- iPad／平板窄橫式：棋號、座標控制與播放鍵固定分成上下兩排。
- 放大、縮小或旋轉後，「座標：開／關」不再被播放控制遮住。
- Samsung Galaxy、Android Chrome、Samsung Internet 改用 pointerup 落子。
- 觸控開始時鎖定棋盤指標，避免瀏覽器捲動或縮放手勢吃掉落子事件。
- 移動手指超過容許距離時不落子，降低滑動誤觸。
- 9／13／19 路共用同一套觸控座標換算。
- 保留 iPad Air、KataGo、SGF、時鐘、形勢判斷與終局計算功能。

## 三星手機測試

1. 進入「人機」。
2. 選擇 9／13／19 路。
3. 按「開始新對局」。
4. 用手指輕點棋盤交叉點，不要拖動。
5. 若網站仍顯示舊版，請重新整理或關閉分頁後再開啟。
