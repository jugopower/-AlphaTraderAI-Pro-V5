# AlphaTrader AI Pro V5 — Build 024.1 Alpha

## 本版目標
KataGo 真實人機對弈核心修正，保留 Build 023 的棋盤、SGF、提子與正式數地功能。

## 修改內容
- 人機對弈使用真實 KataGo 推薦手，不改用本機示範棋力。
- AI 強度選項正式套用於 KataGo 候選手選擇。
- KataGo 第一推薦手不合法時，會自動檢查下一個合法候選手。
- 傳送給後端的 `next_player` 改為目前實際手番。
- 勝率視角以目前實際手番校正。
- 連線失敗時清楚顯示「連線失敗」，避免誤認為 Demo 正常運作。

## 安全原則
- 不修改棋盤繪製核心。
- 不修改提子、劫、禁入點與 SGF 邏輯。
- 不修改 Build 023 正式數地與死子確認。
- Build 023 Stable 應永久保留，不可覆蓋。
