AlphaTrader AI Pro V5 — Build023.0 RC1 Professional Scoring Edition

新增核心功能：
1. 「計算勝負」改為「正式數地」。
2. 進入確認死子模式後，點擊任一死棋，整塊棋會一起標記。
3. 再次點擊可取消標記，也可一鍵清除全部標記。
4. 按「正式計算」後，以日本規則計算：地＋提子＋已確認死子，白方另加貼目。
5. AI 勝率／AI 估值不再取代正式比賽結果。
6. 雙方連續 Pass 後，可直接進入確認死子流程。

建議測試：
- 連續 Pass → 確認死子。
- 點擊一整塊死棋是否全組標紅叉。
- 再點一次是否取消。
- 清除標記、取消、正式計算是否正常。
- 核對黑地、白地、提子、貼目及最終勝負。

注意：RC1 先支援日本規則。死活有爭議時應回棋盤續弈，再重新數地。
