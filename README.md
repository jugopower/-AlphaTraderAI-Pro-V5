# Build022.6 多分支試下版

以 Build022.5.1 穩定版為基礎，新增三組試下分支：A、B、C。

## 新增功能
- 試下過程可將目前變化儲存到 A／B／C。
- 可載入任一已儲存分支，快速比較不同下法。
- 可刪除個別分支。
- 顯示每個分支已儲存的手數。
- 保留原有「套用、重設、取消」功能。
- 新棋局或套用試下後，自動清除舊分支，避免混用不同局面。

## 建議測試
1. 在第 23 手進入試下，走 5 手並儲存為 A。
2. 重設回第 23 手，走另一條 7 手變化並儲存為 B。
3. 分別載入 A、B，確認棋盤及手數正確。
4. 測試取消、重設、套用仍正常。

本版已完成 JavaScript 語法與 ZIP 完整性檢查，仍需在 iPad Safari 實機確認。
